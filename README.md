# ITM
Управление информационными технологиями на предприятии

Работы по курсу ИТМО «Управление информационными технологиями на предприятии», осень/зима 2026.

Все работы выполняются на одном бизнесе — сети фитнес-клубов DDX Fitness (ООО «ИЛОН»). Используются только открытые данные: бухгалтерская отчётность, публикации компании и деловых СМИ, карточки приложений, открытые записи DNS.

## Файлы

| Файл | Что внутри |
|---|---|
| Паспорт_проекта_DDX_Fitness.pdf | Паспорт проекта: выбор бизнеса, подтверждение масштаба, направления выручки, клиенты и каналы, что известно об ИТ на входе |
| ПР1_DDX_Fitness.pdf | Практическая работа №1 «Бизнес и его ИТ»: разложение бизнеса по девяти пунктам, состояние ИТ-функции по признакам, зоны по блокам, реестр допущений, методика замеров |
| ПР1_Реакция_на_сценарии_36_41.pdf | Приложение к ПР1: разбор сценариев 36 (прямые отношения с клиентами посредников) и 41 (аутсорс эксплуатации одному поставщику на пять лет) и то, что они меняют в диагнозе |

## Порядок работ

Паспорт проекта → ПР1 → ПР2 → ПР3 → ПР4 → ПР5. Каждая следующая работа опирается на предыдущую, а реестр допущений ведётся сквозной до ПР5: в ПР1 — номера А1–А20, в реакции на сценарии — Б1–Б14.
