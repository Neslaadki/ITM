# ITM
Управление информационными технологиями на предприятии

Работы по курсу ИТМО «Управление информационными технологиями на предприятии», осень/зима 2026.

Все работы выполняются на одном бизнесе — сети фитнес-клубов DDX Fitness (ООО «ИЛОН»). Используются только открытые данные: бухгалтерская отчётность, публикации компании и деловых СМИ, карточки приложений, открытые записи DNS.

## Порядок работ

Паспорт проекта → ПР1 → ПР2 → ПР3 → ПР4 → ПР5. Каждая следующая работа опирается на предыдущую, а реестр допущений ведётся сквозной до ПР5: в ПР1 — номера А1–А20, в реакции на сценарии — Б1–Б14, в ПР2 — А21–А33.
